明鉴是什么
  • 一个比「判断力」的地方：对可验证的事实预测下注，凭战绩登上天梯榜。题目不评价任何具体的人，只看谁看得准。
  • 初始积分：每位玩家首次进入赠送 1000 分；积分不够时可以借款（信用额度 + 利息 + 逾期罚息，见「我的战绩」）。
  • 彩池赔率：赔率 = 总彩池 ×（1 − 5% 抽水）÷ 该选项彩池。彩池 = 主办方初始池 + 全体玩家真实投注，一边倒的选项赔率低、冷门赔率高。
  • 固定赔率：主办方预先设定，赔付 = 投注额 × 赔率。
  • 揭晓：截止后按建题时选定的方式结算，中奖按最终赔率派彩。已揭晓的问题永久留存在「已揭晓档案」。
  • 三种揭晓方式：① 平台检索（默认）——能通过网络搜索核实的问题，到期后由平台联网查证公开事实并揭晓，任何人不能手动发起；② 公投揭晓——主观议题（如「美国 2027 是否会衰落」），到期后进入公投窗口，一人一票，票数最高的选项为最终结果，平局则投注全额退还；③ 人工揭晓——仅站长可建的 legacy 模式，任何人可按公开事实发起。
  • 分区浏览：大厅按「进行中 / 待平台检索 / 公投中 / 待人工揭晓 / 已揭晓档案」分区；支持按分类、截止时间筛选，按热度、发布时间、奖池等排序。
  • 只押积分：积分不可充值、不可提现、不可转让，与真实货币无关。
