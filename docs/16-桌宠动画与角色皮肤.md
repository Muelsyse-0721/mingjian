## 1. 这版解决的 5 个问题

| 用户反馈 | 处理 |
|---|---|
| 只能切图，不是真动画 | 增加常驻 CSS 动画 + JS 眨眼 + 空闲表情帧序列 + 点击反应动画 |
| 先把声音关了 | `PetVoice` 默认 `enabled=false`，只有手动点「开启声音」才出声，状态存 `jp-pet-voice` |

| 还有白底 | `.sticker` 的背景/边框/阴影全部移除；mini 页 `html/body` 透明；桌面 `COMPACT_CSS` 双保险 |

## 2. 真动画方案

不用 gif、不用外部依赖，全部是持续运行的动画：

```
#pet > .stage        上下浮动   petBob        2.6s  ease-in-out  infinite  translateY 0 → -4px
      > .react       点击反应    WAAPI         happy 跳 / confused 歪头 / sad 下沉 / sleepy 摇
      > .sway        尾巴轻摆   petTailSway   4.6s  ease-in-out  infinite  rotate -1.6° → 1.6°
      > .breathe     呼吸缩放   petBreathe    3.2s  ease-in-out  infinite  scale .98 → 1.02
      > .blink       JS 眨眼    WAAPI         每 4–7 秒一次，scaleY 1 → .94 → 1（190ms）
      > .sticker     <img> 表情 / 皮肤
```

- **空闲表情帧**：`IDLE_FRAMES = ['calm','happy','calm','confused']`，每 1.6–2.4 秒随机推进一帧（`data-face`），形成呼吸式表情变化；有皮肤时只换皮肤图、不换表情。
- **点击反应**：随机 mood → `react()` 播放一套 WAAPI 关键帧；若 mood 是 happy/sad，有 50% 概率在 780ms 后插入第二帧（happy↔sad 互换），满足「点击时插入 2 帧」。
- **无障碍**：`prefers-reduced-motion: reduce` 时所有 CSS 动画 `animation:none`，JS 跳过眨眼、空闲帧与反应动画，退化为静态表情。

## 3. 声音

- `app/js/pet-voice.js`：`readEnabled()` 改为「只有 localStorage `jp-pet-voice === '1'` 才开启」，没有记录一律静音；`setEnabled` 写回 `'1'/'0'`。
- 页面按钮文案明确：`🔇 开启声音（默认静音）` / `🔊 声音开（点击静音）`。
- `pet.js` 的 `speak()` 每次说话前再判一次 `isEnabled()`；桌面版不自动读，用户不开就永远安静。
- 受浏览器自动播放限制，开启声音的点击本身就是解锁手势（先 `PetVoice.prime()` 再 `setEnabled(true)`）。

## 4. 拖动 / 隐藏

### 4.1 独立页 / 桌面版（`app/pet.js`）

- 拖动：`pointerdown → setPointerCapture`，超过 6px 判定为拖动，`left/top` 限制在视口内；位置存 `jp-pet-pos-v2`。
- 单击 vs 双击：单击延迟 260ms 执行互动；320ms 内第二次点击判定为双击 → **隐藏**。
- 隐藏：
  - 独立页：`#pet[hidden]` + 右下「🐟 叫出大肥鱼」按钮，状态存 `jp-pet-hidden`；
  - 桌面版：先气泡提示，900ms 后调用 `window.desktopPet.toggle()` 收起窗口，`Ctrl+Shift+F` 叫回。
- ✕ 按钮与双击等效。

### 4.2 主站浮层（`app/js/pet-embed.js`）

- iframe 内部把指针屏幕坐标 `postMessage({source:'jp-pet', type:'drag', phase})` 给父页面；父页面移动 iframe（`position:fixed` 的 left/top），限制在视口内，结束后存 `jp-pet-pos-v2`。
- 隐藏按钮 ✕（或桌宠内双击）→ `jp-pet-hidden='1'`，iframe `display:none`，左下 🐟 按钮变「叫回」；恢复时清 `jp-pet-hidden`。
- 收起时在底部弹一条 2.2s 的 toast：「大肥鱼躲起来了，点左下角 🐟 叫回」。
- `full` 模式下不接管拖动，桌宠固定在 iframe 右上角，避免遮挡问答面板。

## 5. 透明

- `.sticker { background:transparent; border:0; box-shadow:none; }`

| `skin-grok` | Grok | 黑 + 白 + 冷银，铆钉夹克、抱胸坏笑，叛逆 |

> 全部为原创拟人化 Q 版角色，**不含任何厂商 logo、字母或真实商标图形**，只借用配色与气质区分。

### 6.2 生成与去底

1. ImageGen 生成 1024×1024、纯白平涂背景、贴纸描边、正面全身。
2. Pillow 去白底：
   - 从四角/四边种子做**连通域洪水填充**，只删「近白（min ≥ 218）且低饱和（max−min ≤ 18）」的背景；
   - 对透明区外扩 1px 的浅色像素做毛边清理，保留深色轮廓；
   - 角色内部的白色（衬衫、围巾、书页）因被深色描边包围，不会被误删；
   - `RGBa`（预乘 alpha）缩放，避免白色光晕；
   - 裁切后居中放入 512×512 透明画布。
3. 原始生成图归档在 `app/assets/pet/_src/`，运行时只用 `skin-*.png`。

### 6.4 换装与回退

- 入口：问答面板里的「换装」下拉（`#skin-pick`），仅在非 mini 页显示（桌面紧凑模式由 `COMPACT_CSS` 隐藏）。
- 优先级：`?skin=skin-xxx` > `localStorage jp-pet-skin` > 默认（5 张表情图）。
- 皮肤图走 `#pet .skin-img`；有皮肤时 `.face` 全部隐藏，无皮肤时恢复 5 表情图切换。
- 图片加载失败 → 自动去掉 `has-skin`，回退 `assets/face-calm.png`（`onerror`，`pet.js:applySkin`）。
- 浮层加载 iframe 时，`pet-embed.js` 会把 `jp-pet-skin` 拼到 src 上，主站与独立页皮肤一致。

## 7. 本地存储键

| key | 含义 |
|---|---|

## 参考实现与授权备注（2026-10-19）

调研了两个同类项目，结论如下：

| 项目 | 技术栈 | 授权 | 我们怎么用 |
|---|---|---|---|
| Suy201/muelsyse-desktop | C# / WinForms（仅 Windows） | **未授予开源许可**，且角色为《明日方舟》版权角色 | **只参考交互思路**（拖动、动作按钮目录、水壶互动），未复制任何代码或素材 |
| zhoupengjie/wakuwaku | Tauri + TypeScript | **MIT** | 参考了「Connect → 外部 agent」的产品设计；其 `pets/claude-chan` 为 B 站 UP 主 ZipZipPipe 的像素二创，按用户要求**只作形象参考、不直接使用像素图** |

因此我们的中号 Claude（`skin-claude-medium`）是**原创生成的非像素版本**：3.5 头身、橘发橙花、黑金刺绣奶油裙、捧书，与像素稿同一设计语言但不复制像素素材。

鼠标跟随为本项目自行实现：整层 `.react` 按光标相对桌宠中心的归一化坐标做 ±7° 旋转 + ±5px 位移，
父页面通过 postMessage 转发归一化光标（rAF 节流），可一键关闭。
