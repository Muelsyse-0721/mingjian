# 天梯段位与积分规则

## 一、段位表（八大段，每段内分 I → IV 小段）

| 大段 | 名称 | 总积分 | 一句话描述 |
|---|---|---|---|
| I | 围观群众 | < 200 | 新账号试水 |
| II | 气氛组 | 200–599 | 情绪输出为主 |
| III | 键盘侠 | 600–1299 | 偶有亮点，短板明显 |
| IV | 对线士兵 | 1300–2199 | 能打，论据不稳 |
| V | 辩手 | 2200–3399 | 逻辑在线，谬误稀少 |
| VI | 策论人 | 3400–5199 | 论据扎实，攻守均衡 |
| VII | 纵横家 | 5200–6999 | 全方位成熟 |
| VIII | 国师（传奇） | 7000+ 且全服前 1% | 需人工 + 模型双重确认 |

> 命名可以再商量，结构是：8 大段 × 4 小段 + 传奇段位。

## 二、积分规则

- 总积分 = Σ 单条最终得分（公式见 docs/02）
- **近因加权**：最近 90 天的得分计 100%，90–180 天计 80%，更早计 50%（防止「一篇吃一辈子」）
- 排行榜展示：总积分 + 正分率（正分条数 / 总条数）+ 有效条数
- 升降级：按 90 天滚动积分映射段位；建议「升段看总积分，降段看近因积分」，降低挫败感

## 三、赛季制

- 每 3 个月一个赛季
- 赛季结算：总积分 × 70% 带入下赛季 + 发放段位徽章
- 徽章永久保留历史最高纪录

## 四、防刷与反作弊

- 同一事件、同一用户只计得分最高的 3 条（防刷屏）
- 被删除/隐藏的帖子，对应评分作废并扣回积分
- 明显脚本化内容（批量模板回复）检测 → 不计分
- 模型版本变更时，全量重评或标注「按 vN 标准评分」

## 五、收录规则（排名范围）

- M1/M2：仅限**自愿报名**的用户（自己提交知乎 id + 授权抓取自己的公开言论）
- M3：才考虑公开收录，且需完成 docs/01 的法务评估

## 六、争议处理（排名公开展示的前提）

1. 被评分人可对任一单条评分发起申诉 → 人工复核，48 小时内响应
2. 申诉成立：修正分数或下架该条记录，处理记录公开可查
3. 同一用户连续 3 次申诉成立 → 触发该模型版本全量复查
