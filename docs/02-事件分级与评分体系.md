# 事件分级与评分体系

## 一、事件分级（决定分数区间 R）

| 等级 | 名称 | 典型 | 热度参考 | 分数区间 |
|---|---|---|---|---|
| S | 巨浪 | 重大政策立法、国际大事、顶级社会事件 | 全网热搜 Top、央媒报道、千万级讨论 | **±100** |
| A | 大潮 | 部委新规、行业地震、省级大事 | 百万级讨论、行业媒体刷屏 | **±50** |
| B | 涟漪 | 普通社会新闻、消费/职场争议 | 十万级讨论 | **±25** |
| C | 水花 | 日常对线、评论区掐架 | 无热度指标 | **±10** |

判定方式：

1. 有热度数据（阅读/回答/赞同/媒体报道计数）→ 按量级映射
2. 无热度数据 → LLM 按语义标准判定（输出等级 + 理由）
3. 一条发言涉及多个事件 → 取其主要论述对象定级
4. 分级结果可被人工申诉修正

设计意图：让「在大事件里打出高质量对线」的权重远高于「日常评论区掐架」，同时日常对线也不至于毫无意义（保持活跃度）。

## 二、评分维度（五维，每维 0–100）

| 维度 | 权重 | 评什么 | 红线扣分项 |
|---|---|---|---|
| 论据质量 | 30% | 数据/信源引用；一手 > 二手 > 三手 > 无信源 | **造谣、编造信源 → 大幅扣分** |
| 逻辑严密 | 25% | 论证结构；谬误检测（稻草人/滑坡/非黑即白/偷换概念…） | 每处谬误扣分 |
| 回应针对性 | 20% | 是否正面回应对方核心论点，而不是自说自话 | 全程跑题 |
| 信息增量 | 15% | 新信息/新视角 vs 复读机 | 纯情绪复读 |
| 表达礼仪 | 10% | 就事论事 | 辱骂、扣帽子、人身攻击 |

**红线规则（优先级最高，可一票否决）**：造谣 / 人身攻击 / 歧视言论等 → 该条直接进入负分区，且逻辑分不超过 20。

**对线类内容的特殊处理**：评的是「该条回复本身」，不是整楼；同一帖的多楼对线，取主楼 + 关键回复分别评分。

## 三、计算公式

```
原始分   = Σ(维度分 × 权重)                      # 0–100
校准系数 = 0.6 ~ 1.0                            # 按 LLM 自评置信度
最终得分 = (原始分 − 50) ÷ 50 × R × 校准系数      # 映射到 [−R, +R]
```

- 原始分 50 = 及格线 = 0 分；100 分 = +R；0 分 = −R
- R 由事件等级决定：S=100，A=50，B=25，C=10

## 四、校准与防偏见（上线前必做）

1. **金标准集**：人工标注 100 条（覆盖 S/A/B/C 四级、覆盖不同立场），要求 LLM 与人工打分相关性 > 0.7
2. **立场中立测试**：同一篇论证，正反立场互换措辞，分差须 < 5 分；不达标就改 prompt，不过就不上线
3. **抽检**：每 50 条抽 1 条人工复审，并记录模型版本
4. Prompt 必须显式声明：「你只评价论证质量（论据/逻辑/针对性/礼仪/增量），不评价作者的政治立场；对立场本身持绝对中立。」
