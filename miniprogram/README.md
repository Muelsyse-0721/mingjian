# 明鉴 · 微信小程序

与网站共用**同一个云端数据库**，因此天然是同一份数据：网页写进去，小程序下一次轮询就能看到；小程序下注，网页刷新也能看到。

## 一、导入

1. 打开「微信开发者工具」→ 导入项目 → 选择本目录 `miniprogram/`
2. AppID 填你自己的（`project.config.json` 里现在是 `touristappid`，仅够本地预览，**不能上传**）
3. 编译。若提示域名不合法：详情 → 本地设置 → 勾选「不校验合法域名」（仅开发环境）

## 二、数据同步机制

| 场景 | 机制 |
|---|---|
| 大厅列表 | 每 5 秒轮询 + 下拉刷新 + 切回前台立即刷新 |
| 题目详情/赔率 | 每 5 秒轮询 |
| 天梯 | 每 15 秒轮询 |
| 写入（下注） | 直接 POST 到云端，成功后立即重拉 |

轮询用「内容签名比对」：数据没变就不 setData，避免闪烁。间隔在 `config.js` 的 `POLL_MS` 调。

## 三、生产环境的域名问题（关键）

小程序**不允许**直接请求未在小程序后台配置的域名，且配置的域名必须是已备案域名。
`jp-ladder.app.workbuddy.host` 属于平台域名，你无法在小程序后台完成校验文件，所以**直连在生产环境会被拦**。

两种可行方案：

### 方案 A：云函数代理（推荐，零域名要求）

1. 小程序后台 → 开发管理 → 云开发 → 开通（有免费额度）
2. 开发者工具里右键 `cloudfunctions/api` → 上传并部署（云端安装依赖）
3. 把 `config.js` 的 `USE_PROXY` 改成 `true`

云函数在服务端发起 HTTPS，不受小程序域名白名单限制。`cloudfunctions/api/index.js` 已写好转发逻辑（含 token 透传）。

### 方案 B：自有备案域名

1. 有备案域名后，用 Nginx/Cloudflare Worker 反代 `https://jp-ladder.app.workbuddy.host`
2. 小程序后台 → 开发设置 → 服务器域名 → request 合法域名里填入你的域名
3. `config.js` 的 `BASE` 改成你的域名

## 四、功能范围

- 大厅：五分区（进行中/待检索/公投中/待人工/已揭晓）、下拉刷新、5 秒同步
- 详情：选项与实时赔率、下注（需登录）
- 天梯：按已结算投注计算收益率（≥3 笔），口径写在页面顶部
- 我的：手机号+验证码登录（与网站同一账号体系）、我的投注、退出

## 五、上架审核的真实风险（务必先看）

微信对「竞猜 / 押注 / 赔率 / 派彩」这类形态审核非常严格，即使积分不能兑钱，也很容易被判定为**赌博类内容**而拒绝。建议提交前做文案改造：

- 「下注」→「参与预测」；「奖池」→「参与热度」；「赔率」→「当前倾向」；「派彩」→「结果结算」
- 页面内明确写「积分不可充值、不可提现、不可兑换任何财物」
- 类目选「工具 / 信息查询」，不要选社交或游戏

如果仍被拒，通常是**类目与内容不匹配**，需要按审核意见改，而不是反复提审。
