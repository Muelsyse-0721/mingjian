# 明鉴（原「键政天梯」）

一句话构想：抓取知乎某用户的发言与对线记录，由 AI 按「论证质量」评分；按事件重要度划定分数区间（大事件 ±100，小事件 ±10），累计积分形成天梯排名。联机部分为「预测下注 + 信用借贷」游戏场，更名「明鉴」以求中立、适于传播。

## 三条核心设计原则

1. **评「怎么辩」，不评「辩什么」** — 评分只针对论证质量（论据 / 逻辑 / 针对性 / 增量 / 礼仪），对政治立场绝对中立。这是产品生死线，也是法律安全线。
2. **先评分引擎，后爬虫排名** — MVP 用手动导入的数据跑通「事件分级 → AI 评分 → 个人战报」；自动爬虫和公开排名放到最后一公里。
3. **被评分者可申诉、可下架** — 没有申诉机制的公开排名，法律敞口无限大。

### v1.0 新增：明鉴改名 + 信用借贷 + 百题题库 + 已揭晓档案

- **品牌改名**：「键政天梯 / 见证天梯」→「明鉴」，页面标题、导航、文档同步更换（域名前缀 `jp-ladder` 暂未变，保活已分享链接）

- **破产保护**：净资产跌破 −300 时自动核销全部未清借款（状态置 `written_off`：债务清零、记录留存、本金仍计现金），无死局、可从头再借
- **利息池**：全部已收利息 + 罚息归平台池，站长可划入任意进行中问题的初始彩池（按选项平均分配，全程记录用途）

- **已揭晓档案永久留存**：大厅三态分页（进行中 / 待揭晓 / 已揭晓档案），结束的问题含结果、最终赔率与我的投注复盘，不删除
- **站长台借贷管理**：未结清借款表（可核销）+ 最近结束的借款留档；全局设置新增全部借贷规则参数；CSV 导出新增借贷账单

### v1.1 新增：赛季徽章 + 对线房 + 证据情报站 + 社区仲裁 + 预期指数（2026-10-18 夜间）

- **赛季徽章与预言家战报**（`js/badges.js`）：赛季 = 2026-10-18 起每 90 天；14 枚徽章全部由数据计算（首注/神预言/冷门猎人/五连绝世/破产重生/证据猎人/陪审团员/对线选手…）；「我的战绩」展示本赛季战报（净积分、胜率、最佳/最差单场、连胜纪录、与上季对比），天梯榜增加徽章列
- **邀请制对线房**（`js/debates.js`）：围绕辩题开房（可设邀请码），双方轮次制发言；云端 LLM 按五维（论据/逻辑/针对性/增量/礼仪）各 20 分点评，LLM 不可用自动降级规则分；观众押注走彩池赔率（抽水 5%，平局全额退还），结算时镜像进 `jp_bets`，打通积分/流水/天梯/徽章
- **AI 证据情报站**（`js/evidence.js`）：每个问题下一面证据墙——任何人可提交带链接的公开证据，社区投票排序，站长采纳/驳回；AI 只做中立整理（本地兜底）；揭晓时被采纳且立场命中的证据提交者奖 50 分；另设信源质量榜
- **社区仲裁**（`js/arbitration.js`）：押过题的人可对揭晓结果发起仲裁（理由 + 提议结果，每问一次）；任何人质押 10–500 分投票（一票制，发起人不能自投）；≥3 票且同意占比 ≥60% → 社区支持改判，站长执行（按新结果原地重算全部投注派彩，旧结果/旧赔率/执行人全留痕）或驳回（质押全额退回）；押对边一方分走押错边一方的质押；裁决成立而客户端中断时，下次刷新自动兜底结算（幂等）
- **赔率曲线 + 预期指数**（`js/oddscurve.js`）：彩池题在开盘/下注/利息池注入时写 `jp_odds_snaps` 快照（同题 10 分钟节流）；题卡内嵌迷你走势曲线（首选项市场概率）；新增「预期指数」视图——全部进行中彩池题的概率墙 + 市场平均概率 + 中性口径文案（只描述投注分布，不预测不建议）
- **数据表扩到 12 张**：新增 `jp_debates / jp_debate_posts / jp_debate_bets / jp_evidence / jp_disputes / jp_dispute_votes / jp_odds_snaps`（均公开读写策略，round-trip 全过）
- **口径统一**：非投注行（奖励 bonus / 质押 stake / 差额 adjust）计入现金与流水，不计胜场、不入投注 CSV；仲裁质押在结算前计入「在押」，榜单净资产与玩家视角一致

### v1.2 新增：防滥用揭晓 + 公投结算 + 分类浏览（2026-10-18）

- **揭晓方式三分**（建题时选定，防滥用核心）：到期后**一般不允许人发起揭晓**
  - **平台检索**（默认）：能通过网络搜索核实的问题，到期后进「待平台检索」区，由平台联网查证公开事实后揭晓（每日自动检索 + 站长兜底）；任何人无手动揭晓入口
  - **公投揭晓**：主观议题（如「美国 2027 是否会衰落」），到期后进「公投中」区，一人一票、截止前可改票；投票截止后按多数决自动结算，**平局则投注全额退还**；无人投票则转人工
  - **人工揭晓**：legacy 模式，仅站长可建，任何人可按公开事实发起
- **大厅五分区**：进行中 / 待平台检索 / 公投中 / 待人工揭晓 / 已揭晓档案（结束问题永久留存）
- **浏览优化**：题卡带分类标签；工具条支持按分类、截止时间（7/30/90 天内、今年、明年起、无截止）筛选，按热度（投注+奖池）、发布时间、奖池、截止时间排序
- **数据**：新增 `jp_public_votes` 表（公投，qid+uid 唯一，可改票）；`jp_questions` 增加 `settle_mode / category / vote_end` 列；100 道题库题回填分类与 `settle_mode=search`
- **平台检索工具**：`app/tools/platform-search.js`（`list` 查到期题 / `settle` 按事实揭晓，幂等、含证据奖励）；已配每日 09:00 自动检索（设置里可查看暂停）
- 归档展示揭晓方式与分类；平局题显示「公投平局 · 投注全额退还」
